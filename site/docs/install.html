Install

ReHub runs in Docker. The installer starts two containers, checks that the tools work, prints the address and opens it.

Requirements

NeedDetail
DockerDocker Desktop or Docker Engine, with Compose v2 (docker compose).
DiskAbout 280 MB for the image, plus space for your evidence. Evidence is kept in a Docker volume named rehub-data.
MemoryThe engine container is limited to 4 GB by default. Set REHUB_MEMORY to change it.
NetworkOnly to pull the image the first time. After that ReHub works offline.
BrowserAny current browser. The page is plain HTML, CSS and JavaScript with no build step.

Platforms

PlatformStatus
macOS, Apple silicon, Docker DesktopTested end to end, including the one-line install from a clean home.
Linux (amd64, arm64)The image is built for both in CI. Installing on Linux is untested.
Windows with WSL 2Untested.
macOS, IntelThe amd64 image should run. Untested.

One line

curl -fsSL https://raw.githubusercontent.com/Ani07-05/rehub-engine/main/scripts/install.sh | sh

The same file is served from this site at /install.sh. It is one short script with the compose file inside it, so you can read all of it first:

curl -fsSL https://raw.githubusercontent.com/Ani07-05/rehub-engine/main/scripts/install.sh -o install.sh
less install.sh
sh install.sh

To pin an exact version, replace main in the address with a tag or commit.

The installer writes its files to ~/.rehub, pulls the image, starts the stack, runs the doctor, prints the address (http://localhost:8080 by default) and opens it.

From a checkout

git clone https://github.com/Ani07-05/rehub-engine
cd rehub-engine
./scripts/install.sh --local

--local builds the image from the checkout instead of pulling it.

Installer options

OptionWhat it does
--localBuild the image from the checkout.
--port NPublish the UI on this port. Default 8080. Also REHUB_PORT.
--authTurn on the access token. A sign-in link is printed.
--no-openDo not open the browser.
--updatePull the newest image and restart.
--statusShow what is running.
--uninstallStop and remove the containers. Your investigations are kept.
--uninstall --purgeAlso delete the investigations.

Environment variables the installer reads: REHUB_HOME (default ~/.rehub), REHUB_PORT, REHUB_IMAGE (default ghcr.io/ani07-05/rehub-engine:latest) and REHUB_PROJECT (the Compose project name, default rehub).

What it starts

  • engine parses the evidence. It sits on a network with no route out, has a read-only root, all Linux capabilities dropped, no-new-privileges, and memory and process limits. It publishes no ports.
  • gateway is a small TCP forwarder (about 50 lines) that publishes the UI on 127.0.0.1 only.

First run

Open the address. A REHUB screen checks Storage, Zeek, Suricata and tshark, including a self-test on a small built-in capture, one service at a time from left to right. When all pass, press Enter.

You can run the same check from a terminal: docker compose -p rehub exec engine rehub --data /data doctor.

Remove it

sh install.sh --uninstall           # stop it, keep your investigations
sh install.sh --uninstall --purge   # also delete them
