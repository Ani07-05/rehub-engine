How it works

The tools are good at their own jobs. The engine's job is to line their output up and say where they agree.

The pipeline

  1. Identify. Each file is typed by its content, hashed with SHA-256 and stored once. Archives are unpacked with limits.
  2. Run the tools. Zeek, Suricata and tshark run on each capture inside the container, with no network.
  3. Normalize. An adapter per tool turns its output into one Event schema, and keeps which tool and which file line it came from.
  4. Correlate. Events are joined into conversations and detections (below).
  5. Join the PLC. PLC projects are parsed. Writes seen on the wire are linked to variables and logic.
  6. Write the record. One JSON record per investigation, which the UI and the report read.

Correlation

  • Flow identity. Community ID v1, implemented in ReHub and checked against Zeek and Suricata, so the same conversation has the same key in every tool.
  • Modbus commands. Matched by flow, transaction id and function code. A gap of more than 2 seconds splits reused transaction ids into separate commands.
  • Corroboration. A detection is corroborated when two independent tools report it.
  • Attribution. MAC addresses come from ARP replies first. A gateway or shared MAC is flagged. ARP conflicts are reported.
  • ATT&CK for ICS. Candidates such as T0855 (Unauthorized Command Message), T0836 (Modify Parameter) and T0858 (Change Operating Mode).

PLC analysis

ReHub parses Structured Text, PLCopen XML and Rockwell L5X. It finds variables, the logic that reads them and the outputs they drive. A Modbus register write is linked to a variable by assuming wire address N is %MW N, which is the default on Schneider M580 and CODESYS. The page shows that assumption next to every link, because your device may be configured differently.

Why it is local

OT evidence often contains network layouts and device names that cannot leave a site. The engine container cannot reach anything outside, so a bug or a malicious capture cannot send data out. The gateway is the only thing that publishes a port, and only on 127.0.0.1.
