Reference

Evidence kinds

ReHub identifies each file by its content, not its name. A zip, tar or gzip of files is unpacked with limits (at most 5000 files and 16 GiB expanded).

KindAnalyzedNotes
pcap, pcapng (also gzipped)YesRun through Zeek, Suricata and tshark.
Zeek logs (TSV or JSON)YesRead directly.
Suricata eve.jsonYesAlerts joined with the other tools by Community ID.
PLC Structured Text (.st)YesStatic analysis; variables and logic linked to Modbus writes.
PLCopen XMLYesDTDs and entities are rejected.
Rockwell L5XYesDTDs and entities are rejected.
tshark JSON, syslog, CSV asset lists, CSV historian exportsNoStored and hashed. Listed as stored but not analyzed yet.
Anything elseNoStored and hashed.

HTTP API

The UI uses this API. It is local only and has no stability promise yet. Every change (POST, PUT, DELETE) needs the header X-Rehub: 1 and a matching Origin.

RequestDoes
GET /api/healthLiveness and whether sign-in is on.
GET /api/doctorRun the tool checks.
POST /api/investigationsCreate an empty investigation. Returns its id.
PUT /api/investigations/ID/files?name=NAMEUpload one file as the request body.
POST /api/investigations/ID/runStart analysis. Body: {{"plc_ips": {{"pump.st": "10.0.0.20"}}}}.
GET /api/investigationsList investigations.
GET /api/investigations/IDStatus and, when done, the full record.
DELETE /api/investigations/IDDelete one.
GET /api/investigations/ID/evidence/SHADownload an evidence file.
GET /api/investigations/ID/evidence/SHA/lines?start=&count=Read lines of a file with context.
GET /api/investigations/ID/flows/KEY/packets?limit=Packets of one conversation.
POST /api/demoAnalyze the built-in demo.
POST /api/logoutClear the sign-in cookie.

Security model

  • Binds to loopback. A Host allowlist guards against DNS rebinding.
  • Every change needs the X-Rehub header and a matching Origin.
  • Evidence is only served as a download. Every string that comes from a file is shown as text, never as HTML.
  • Strict Content Security Policy with no inline script or style.
  • Upload size caps, sanitized file names, and limits on zip, tar and gzip expansion.
  • PLC XML with DTDs or entities is rejected.
  • Optional access token, turned into an HttpOnly, SameSite=Strict cookie.
  • The engine container has no route out, a read-only root and no capabilities.

Known limits

  • Suricata runs with ReHub's own rules only. The Emerging Threats Open set is not bundled.
  • Correlation holds all events in memory. Very large captures have not been tested.
  • The tool versions used are pinned in the image but not yet written into each investigation record.
  • Only tested on macOS with Apple silicon. See Platforms.
  • ATT&CK for ICS mappings (T0855, T0836, T0858) are candidates. They show the technique a behavior is consistent with, not that an attack happened.
